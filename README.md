# 💸 Expense Tracker – Full Stack MERN Application

A modern **Expense Tracker Web Application** built using **React (Vite)**, **Node.js**, **Express**, and **MongoDB**.  
The app allows users to **register with OTP verification**, **login securely**, and **manage their expenses** through a clean, responsive dashboard with analytics.

---

## 🚀 Features

### 🔐 Authentication
- User Signup with **Email OTP verification**
- Secure Login using Email & Password
- Only verified users can log in
- Session handling using `localStorage`
- Logout functionality

### 👤 User Profile
- Profile shown on dashboard (Name, Email, Mobile)
- Profile displayed in left sidebar
- Username dropdown in header

### 💸 Expense Management
- Add Income & Expenses
- Expense categories (Food, Travel, Shopping, Bills, etc.)
- Date & time tracking
- Delete expenses
- User-specific data (each user sees only their expenses)

### 📊 Analytics
- Monthly Expense **Bar Chart**
- Real-time chart updates on adding expenses

### 🎨 UI / UX
- 3-column dashboard layout  
  **Profile | Core Dashboard | Charts**
- Sticky header
- Responsive (mobile & desktop)
- Clean card-based UI
